# MovieLens 25M Movie Recommendation System

## 1. Project Overview

This project implements a movie recommendation system using Big Data technologies. It uses the MovieLens 25M dataset, Apache Hadoop HDFS for data storage, Apache Spark for data processing, and Spark MLlib's Alternating Least Squares (ALS) algorithm for collaborative filtering.

The system processes movie ratings, trains a recommendation model, evaluates its predictions, generates recommendations, and visualizes the results.

## 2. Technologies Used

- Python
- Apache Hadoop HDFS
- Apache Spark and Spark MLlib
- ALS Collaborative Filtering
- Pandas and Matplotlib (where used for visualization)
- Git and GitHub

## 3. Dataset

The project uses the MovieLens 25M dataset provided by GroupLens Research.

**Dataset:** https://grouplens.org/datasets/movielens/25m/

The dataset contains approximately 25 million ratings, along with movie metadata. The ratings data is used to train and evaluate the recommendation model.

## 6. Steps to Reproduce

### Step 1: Download the dataset

Download and extract the MovieLens 25M dataset. Upload the required files to the HDFS paths expected by the project scripts.

Example:

```bash
hdfs dfs -mkdir -p /user/<USERNAME>/movielens25m
hdfs dfs -put /path/to/ml-25m/ratings.csv /user/<USERNAME>/movielens25m/
```

Adjust the paths according to your configuration and the source code.

### Step 2: Load the data

```bash
python src/09_load_25m_from_hdfs.py
```

Loads the rating data from HDFS into the processing workflow.

### Step 3: Train the ALS model

```bash
python src/10_train_25m_als.py
```

Trains the collaborative-filtering model using Spark MLlib.

### Step 4: Evaluate the model

```bash
python src/11_evaluate_25m_als.py
```

Evaluates the model's rating predictions using the implemented evaluation metrics.

### Step 5: Generate recommendations

```bash
python src/12_generate_25m_recommendations.py
```

Generates movie recommendations using the trained model.

### Step 6: Visualize the results

```bash
python src/13_visualize_25m_results.py
```

Generates visualizations for analyzing rating patterns and model predictions.

**Note:** Run the scripts in order and ensure that the required input files and intermediate outputs are available. Check the scripts for their configured paths and dependencies.
